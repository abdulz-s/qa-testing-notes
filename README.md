# QA Testing Notes

A collection of practical QA notes built from my learning projects and testing experience.

## Purpose

This repository is not intended to be a textbook about software testing.

It is a living collection of practical examples showing how I apply QA thinking to real scenarios, including test design, exploratory testing, requirements analysis, and risk-based testing.

The goal is to improve how I approach testing by moving beyond randomly clicking through an application and thinking more systematically about:

* What could fail?
* Where are the highest risks?
* What inputs and conditions should be tested?
* What requirements are unclear or missing?
* What evidence would help investigate a problem?

## Topics

### Test Design

* Boundary Value Analysis
* Equivalence Partitioning
* Decision Tables
* State Transition Testing

### Requirements Analysis

* Finding ambiguous requirements
* Identifying missing requirements
* Recognizing possible contradictions
* Turning requirements into test scenarios

### Exploratory Testing

* Test charters
* Session-based thinking
* Risk-based exploration
* Error guessing

### Practical Investigation

* Reproduction steps
* Evidence collection
* Network and console investigation
* Device and environment information

## How I use this repository

After a learning project or testing experience, I add short practical examples showing how a testing technique could be applied.

The focus is on understanding and applying the technique rather than collecting long theoretical notes.

## Privacy and confidentiality

Examples in this repository are anonymized.

No private client information, confidential URLs, tester accounts, credentials, internal instructions, screenshots from private test cycles, or personal user data are included.
